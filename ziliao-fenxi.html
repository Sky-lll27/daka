公式速查（背这一页）

【术语】增长量 = 现期 − 基期（有正负，负值=减少量）
        增长率 r = 增长量基期 = 现期基期 − 1
        基期量 = 现期量1+r
【增长量】增长量 = 现期1+r × r ；r≈1n 时 = 现期n+1
【间隔增长率】r = r1 + r2 + r1×r2  （r1、r2 是两个相邻期间增速）
【混合增长率】介于两者之间，偏向基期量大的（没基期用现期近似）
【年均增长率】现期 = 基期 × (1+年均增长率)^n
【比重】现期比重 = AB
        基期比重 = AB × 1+b1+a   ← a=部分增速，b=整体增速
        两期比重差 = AB × a−b1+a
        判断升降：a>b 比重上升；a<b 比重下降（只看增速，不用算）
【倍数】现期倍数 = AB ；基期倍数 = AB × 1+b1+a
【平均数】平均数增长率 = a−b1+b   ← a=总量增速，b=份数增速

题目问什么 → 用哪个公式（按句子里的事来判）

题干里出现这些字题型公式
「增长了百分之几」「增速」「增幅」「回落/提高几个百分点」增长率r = 现期基期 − 1
「比……增长/减少多少（带单位）」「增加……万元」增长量现期1+r × r
「比前年（隔一年）增长」间隔增长率r = r1+r2+r1×r2
「两类合成一类，求整体增速」混合增长率居中偏大（线段法）
「占……比重」「比重是多少」现期比重AB
「上年（基期）比重」基期比重AB × 1+b1+a
「比重比去年上升/下降几个百分点」两期比重差AB × a−b1+a
「是……的几倍」「A 比 B 多几倍」倍数AB（多几倍再减 1）
「平均每……」「人均」「单位面积」平均数总量/份数
「平均数的增速」平均数增长率a−b1+b

三条铁律（每天做资料前先念一遍）

  • 先圈问句：问的是累计还是新增？是比重还是比重差？圈错方向，算得再快也是错的。
  • 一次算完不回头：草稿写完整一行（截位 → 分数 → 一次除完 → 直接选），只有选项差 <1% 才精算。
  • 最后一题综合判断照旧放弃：在草稿写「放弃」两个字，别花 70 秒去蒙。

补充 · 2026-11-28 手写笔记里页面缺的 7 条

【① 交叉相乘比大小】分数比较第 ④ 条（原来只有"直除比较"）
  比 a/b 与 c/d → 算 a×d 与 c×b，谁大原分数就大
  例：58/81 与 61/85 → 58×85=4930，61×81=4941 → 后者大
  用途：四个选项比比重大小、两个增速比大小（两次乘法，15 秒，不产生小数误差）

【② 乘法估算（凑整）】A×B ≈ A↑×B↓
  99×101 ≈ 100×100；适用"两个因数都贴近整十/整百"的乘法

【③ 翻番】一番＝2 倍，n 番＝2^n 倍
  "翻两番"＝4 倍；"翻三番"＝8 倍。"增长了 X 倍" ≠ "翻了 X 番"，别看混

【④ 顺差 / 逆差】外贸题先定符号
  顺差（挣钱）＝出口 − 进口；逆差（赔钱）＝进口 − 出口

【⑤ 拉动增长】拉动多少（个百分点）＝ 部分增长量 ÷ 整体基期值
  ＝ [A/(1+r1) × r1] ÷ [B/(1+r2)]
  问法："某部分拉动整体增长几个百分点"

【⑥ 两期比重差：量级秒杀】页面有公式，但没有这条用法
  比重差 = (A/B) × (a−b)/(1+a)
  ∵ (A/B) 小于 1 且 1/(1+a) 小于 1  →  |比重差| 小于 |a−b|
  用法：选项里比 |a−b| 还大的，直接排除，不用算
  例：a−b = 2.1 个百分点，选项 3.5 / 2.8 / 1.2 → 只剩 1.2

【⑦ 年均增长率：n 数"年份差"，不数"年份个数"】
  2013→2015：中间没有基期年 → n = 2
  若把 2012 当基期（跨 12/13/14/15）→ n = 3
  题干给两期就问年均 → 先算年份差，别去数"写了几个年份"

补充二 · 全部速算技巧（每条都配最简单例子）

【① 尾数法】加减题，只看末位
  适用：求两个数相加/相减，且选项末位互不相同
  例：7856 + 4932 → 6 + 2 = 8 → 直接选末位是 8 的选项（不用算完整加法）
  好处：不碰千位、不碰进位，专治"千位少 1"这种错

【② 差分法】两个分数分子分母都在变大，比差值分数
  第 1 步：找出"分子大、分母也大"的那个 → 叫【大分数】，另一个叫【小分数】
  第 2 步：算差值分数 =（大分子 − 小分子）÷（大分母 − 小分母）
  第 3 步：拿差值分数去和小分数比：
         差值分数 更大 → 大分数 更大
         差值分数 更小 → 大分数 更小
  ── 例 A（差值分数更大）比较 3/5 和 4/6 ──
     大分数 = 4/6，小分数 = 3/5
     差值分数 =（4−3）÷（6−5）= 1÷1 = 1
     1 比 3/5（=0.6）大 → 大分数更大 → 4/6 大于 3/5（0.667 大于 0.600，对）
  ── 例 B（差值分数更小）比较 3/4 和 5/7 ──
     大分数 = 5/7，小分数 = 3/4
     差值分数 =（5−3）÷（7−4）= 2÷3 ≈ 0.67
     0.67 比 3/4（=0.75）小 → 大分数更小 → 5/7 小于 3/4（0.714 小于 0.750，对）
  ── 例 C（相等的情况）比较 100/200 和 101/202 ──
     差值分数 = 1÷2 = 0.5，小分数 = 100/200 = 0.5 → 一样大 → 两个分数相等（都是 0.5，对）

【③ 比大小时到底用哪个】决策三行
  数字是 1~2 位数  → 直接除，一位小数
  数字是 3~4 位数  → 交叉相乘（a×d 比 c×b）
  数字是 5 位以上、乘起来太费 → 差分法
  分子分母一增一减（一个变一个不变）→ 不用算，一眼判（分子大分母小就大）

【④ 比重差 ≈ 现期比重 × (a−b)】估算用
  完整式是 (A/B) × (a−b)/(1+a)；a 小于 10% 时 1+a≈1，所以
  例：现期比重 30%，a−b = 2 个百分点 → 比重差 ≈ 0.3 × 2 = 0.6 个百分点
  注意：只能用来估，选项挨得很近时别用

【⑤ 基期和 / 基期差 的两条捷径】
  两个部分增速接近（a≈b）→ 基期和 = 现期和 ÷ (1+a)（不用分别算再相加）
  增速差得多 → 老老实实分别算基期再加减
  例：A 现期 120（增 20%）、B 现期 110（增 20%）→ 基期和 = 230 ÷ 1.2 ≈ 192

【⑥ 增长量近似】当 r 小于 10% 时
  增长量 ≈ 现期 × r（省掉 ÷(1+r) 那一步）
  例：现期 5000，增长 8% → 增长量 ≈ 5000×8% = 400（精确值 370，误差 8%）
  边界：选项差距小于 10% 时不能用，改用 r=1/n 的特殊分数表

【⑦ 基期比重 ≈ 现期比重】只在 a、b 都很小时成立
  (1+b)/(1+a) 在 a、b 都小于 5% 时约等于 1
  例：a=2%、b=3% → (1.03)/(1.02)≈1.01 → 基期比重 ≈ 现期比重，可直接比大小
  a、b 有一个大于 5% → 必须用完整式

【⑧ 年均增长率比较】n 相同 / n 不同
  n 相同 → 直接比 现期/基期（不用开方）
  n 不同 → 用特殊值试探：1.1^3≈1.33、1.1^5≈1.61、1.2^5≈2.49、1.5^3≈3.38
  例：A 五年 2.49 倍、B 三年 1.33 倍 → A 年均 20%、B 年均 10% → A 高

【⑨ 平均数增长率的正负判别】不用算
  a 大于 b → 平均数上升；a 小于 b → 下降（公式 (a−b)/(1+b)，分母必为正，看分子符号）

【⑩ 三个词的口令 + 单位先抄】
  占 = 部分 ÷ 整体；比 = 前者 ÷ 后者；百分点 = 两个百分数相减（出现它一定是"差"，不是"率"）
  动手前先把单位抄在草稿边上（万亿 / 亿 / 万），量级错一个零，全盘错

基期与现期

概念含义例子
基期 / 基期量作为对比参照的那个时期「2017 年比 2016 年增长 6.8%」→ 2016 年是基期
现期 / 现期量相对基期的那一期上例里 2017 年是现期
找法句子里的「比」字后面是基期「A 比 B 增长」→ B 是基期

增长量 vs 增长率（最容易混的一对）

项增长量增长率
定义现期与基期的绝对差增长量与基期的比值
公式现期 − 基期增长量基期 = 现期/基期 − 1
单位有单位（万元、万人）无单位（%）
正负有正负，负值=减少量可为负，「减少率」本质是不带负号的增长率

高频易错：倍数和百分比不是一回事

「2017 年产值比 2016 年增长 280%」
=「增长 2.8 倍」
=「2017 年是 2016 年的 3.8 倍」

规律：是原来的 (1+r) 倍；比原来多 r 倍。
反问：A 比 B 增长 3.2 倍，A 是 B 的几倍？答案 4.2 倍。

年均增长量与年均增长率

年均增长量 = 现期量 − 基期值间隔年份

年均增长率：现期量 = 基期量 × (1 + 年均增长率)^n
（n = 相差年份；n 比「数出来的年份个数」少 1）

截位直除法（最常用，先学这个）

项规则（讲义原文）
保留位数四舍五入最多保留三位有效数字
判定位数①（看选项首位）选项首位均不同 → 保留 两位；首位有相同 → 保留 三位
判定位数②（看选项误差）选项之间误差 >10% → 保留两位；<10% → 保留三位
一步除式只估算分母（分子不动）
多步连除分子分母同时截位，除到能选出答案就停

例：截位直除怎么用

【真题·2015 年 F 省】城镇消费品零售额 9448.57 亿元，增长 12.2%；乡村 1057.36 亿元，增长 14.1%。
问：2015 年城镇约是乡村的多少倍？ A.8.2　B.8.5　C.8.6　D.8.9

做法：9448.571057.36
· 选项首位都是 8，保留三位b>：94491057
· 一步除式只截分母：1057 → 1060
· 94491060 ≈ 8.91 → 接近 8.9，选 D

若按「保留两位」会算成 9411=8.5，落到 B，就错了。选项首位相同必须留三位。

分数比较（比大小，不算出结果）

情况判法（讲义原文）
①分子大、分母小 → 分数大（直接判）
②分子分母同向变大时看变化速度：分子变化大 → 分数大；分母变化大 → 分数小
③拿不准时用直除比较（各除一位小数）

特殊分数怎么用

看到 r≈1n，就把除法变成一次除法：增长量 = 现期n+1

例：增长率 5.5% ≈ 118 → 增长量 = 548519 ≈ 289
　　增长率 3.7% ≈ 127 → 增长量 = 93428 ≈ 33
　　增长率 2.3% ≈ 143 → 增长量 = 168344 ≈ 38

不背这张表，就要算 「现期1+5.5%×5.5%」，多两步且容易错。

一般增长率

增长率 r = 增长量基期量 = 现期量基期量 − 1

基期量 = 现期量1 + r          ← 求去年的值
增长量 = 现期量 − 基期量 = 基期量 × r = 现期量1+r × r

间隔增长率（隔一年）

r(隔期) = r1 + r2 + r1 × r2

r1、r2 = 相邻两个期间的增长率（取较大两个年份的）
题型特征：2017 年比 2015 年增长多少 / 2016 年一季度比 2014 年一季度

间隔增长率：r1×r2 的三种大胆估法（讲义原文）

  • ① a% × b% = (ab)/100 %（把两个百分数相乘化成百分数）
  • ② 一个化成分数、一个不变（如 12.5% × 8% → 1/8 × 8% = 1%）
  • ③ r1、r2 都小于 10% 时，r1×r2 ≈ 1%，大胆估。

例：间隔增长率

【真题】2015 年全国困难群众受益 1838.4 万人次，同比增长 8.5%，增长率较上一年下降 27.5 个百分点。
问：2015 年受益的困难群众较 2013 年增长约？ A.27.6%　B.34.5%　C.40.4%　D.47.6%

做法：
· 2015 年 r1 = 8.5%；2014 年 r2 = 8.5% + 27.5% = 36%
· r = 8.5% + 36% + 8.5%×36% = 44.5% + 3.06% ≈ 47.6%
· 选 D

注意「下降 27.5 个百分点」＝ 去年更高，要加回去。这是最容易反的一步。

混合增长率

混合增长率：大小居中，偏向基期量大的那一方
注：考试中没有基期量，用现期量近似代替

线段法：混合值落在两个分量之间，距离与量成反比
　　　靠近谁 → 谁的量更大

例：混合增长率（线段法）

【真题】城镇人均可支配收入 49283 元、农村 20133 元、全国 36883 元，问城镇与农村人数之比。

线段法：
农村 20133 ——[16750]—— 全国 36883 ——[12400]—— 城镇 49283
人数比 = 右段距离 : 左段距离 = 12400 : 16750 ≈ 1.35 → 约 4:3

口诀：交叉相减，距离比 = 量的反比。 混合值离谁近，谁的量就大。

增长量公式

增长量 = 现期量 − 基期量
　　　 = 基期量 × r
　　　 = 现期量1+r × r      ← 考试最常用
　　　 ≈ 现期量n+1          ← 当 r≈1n 时（特殊分数法）

增长量大小比较（讲义原文）

情况怎么比
① 现期值大、增长率也大大大则大，直接判最大
② 差距小时近似比较 现期量 × r 的乘积大小
③ 乘积接近时列出完整式子 现期1+r×r 再估
④ 增长率差距 >20%必须列完整式子，不能近似

例：增长量计算

【真题】2012 年末全国就业人员 76704 万人，比上年末增加 284 万人；其中城镇 37102 万人，增加 1188 万人；乡村 39602 万人。
问：相较于 2011 年，2012 年乡村就业人员（　）
A.减少 904 万人　B.增加 904 万人　C.增加 1472 万人　D.减少 1472 万人

做法：
· 全国增 284、城镇增 1188 → 乡村 = 284 − 1188 = −904
· 负号 = 减少，选 A

这题不考除法，考「整体增量 = 各部分增量之和」。 看到「其中」就知道要拆。

现期比重

比重 = 部分值整体值 = AB

整体值 = 部分值比重
部分值 = 整体值 × 比重
技巧：截位直除

基期比重（求去年的比重）

基期比重 = 01
　　　　 = AB × 1+b1+a

A = 部分现期量，a = 部分增速
B = 整体现期量，b = 整体增速

两期比重差（今年比重 − 去年比重）

两期比重差 = 现期比重 − 基期比重
　　　　　= AB × a − b1+a

判断升降（不用算）：
　a > b → 比重上升
　a < b → 比重下降
应用技巧：a1+a ≈ 1，所以 |比重差| ≈ |AB × (a−b)|

⚠ 两个公式别混（你在这里错过）

问的是什么用哪个长什么样
「上限/基期比重是多少」基期比重AB × 1+b1+a　—— 求一个值
「比重比去年上升/下降几个百分点」两期比重差AB × a−b1+a　—— 求一个差值
「比重是上升还是下降」只用比增速a 与 b 比大小，根本不用算
「是几倍」「多几倍」倍数AB；「多几倍」再 − 1

例：两期比重（只判升降，不计算）

【真题】2016 年 1–4 月全国全社会用电量同比增长 2.9%；第一产业增 9.1%、第二产业增 0.2%、第三产业增 10.0%、城乡居民增 9.5%。
问：三次产业中，用电量占全社会比重高于上年同期水平的产业有几个？

做法：只看增速与 2.9% 比大小
· 第一产业 9.1% > 2.9% → 上升 ✓
· 第二产业 0.2% < 2.9% → 下降 ✗
· 第三产业 10.0% > 2.9% → 上升 ✓
· 共 2 个 → 选 C

这类题 15 秒能做完，前提是知道「只比增速」。

倍数

现期倍数 = AB

基期倍数 = 01
　　　　 = AB × 1+b1+a

注意：「A 是 B 的几倍」= AB；「A 比 B 多几倍」= AB − 1

平均数

现期平均数 = 总量份数（人均、单位面积、平均每场…）

基期平均数 = 现期平均数 × 1+b1+a   （a=总量增速，b=份数增速）

平均数增长率 = a − b1 + b

例：平均数（分数比较）

【真题】2013 年 1–4 月某市电影院线：1 月场次 10.91 万场、观众 3.50 百万人次；2 月 9.79、3.36；3 月 11.07、3.17；4 月 11.13、3.72。
问：2013 年 1–4 月平均每场电影观众人数最少的月份是？

做法：比 观众场次，不除出来，用分数比较
· 1 月 3.5010.91、2 月 3.369.79、3 月 3.1711.07、4 月 3.7211.13
· 3 月分子最小、分母最大 → 分数最小 → 选 3 月

「分子最小分母最大」是最快的一档判断，别真去除。

⚠ 减少型特殊分数（模考①错点）

增长 r≈1n：增长量 = 现期n+1
减少 r≈1n：减少量 = 现期n-1      ← 分母变小，不是变大

原理：现期 = 基期 × (1−r)，基期 = 现期1−1/n = 现期 × nn-1
　　　减少量 = 基期 − 现期 = 现期n-1

例：某量减少 5%（120），现期 190 → 减少量 = 19019 = 10

⚠ 平均数增长率（模考①错点）

平均数增长率 = a − b1 + b

a = 总量（分子）的增速
b = 份数（分母）的增速

注意：分母是 (1+b)，不是 (1+a)，也不是 (1+a)(1+b)。

例：人均收入 = 总收入人数
　　总收入增速 a = 8%，人数增速 b = 3%
　　人均收入增长 = 8%−3%1+3% = 5%1.03 ≈ 4.85%

⚠ 特殊分数只背到 1/20，超出的硬算

12 ~ 120 背熟就够（1.3%、2.3%、3.7% 这类不在表里）

遇到不在表里的百分数：
· r < 2%  → 直接用「现期 × r」，误差 1~2%，选项差距通常 5~10%，可忽略
· r ≥ 2%  → 硬算：现期1+r × r

别为了凑分数去猜 177、143 这种——猜错反而错得更远。

⚠ 综合判断最后一题：直接蒙，不读题

资料每道大题的最后一道「综合判断」有四个选项要逐个验证，
一题能吃掉 60~90 秒。

正确做法：看到这类题，直接选一个走人（5 秒），把时间还给前面 3 题。
错误做法：想放弃但还在犹豫——既不读题也不选，卡在那里最亏。

模考①实测：20 题用 37 分钟（111 秒/题），超时 11 分钟，
就是因为这类题在犹豫。目标 78 秒/题。

我的错题 · 记「公式套错」和「问句看反」

资料分析错题多半不是算错，是公式用错或问句看反。记两条就够：① 问的是什么（累计/新增、比重/比重差）② 我套了哪个公式、该用哪个。数据存在本机浏览器，重要内容用「导出」备份。

用法：做资料前先扫「总览」的速查卡；做完错题记进「我的错题」，重点记公式套错和问句看反。
